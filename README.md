# Site institucional — Integrare Soluções em TI

Versão redesenhada com direção visual premium, responsiva e pronta para publicação na Vercel.

## Publicação rápida
1. Crie um repositório no GitHub chamado `site-institucional`.
2. Envie todos os arquivos desta pasta para o repositório.
3. Na Vercel, clique em **Add New > Project**.
4. Importe o repositório e clique em **Deploy**. Não é necessário configurar build.
5. Após a publicação, adicione `integrareti.com.br` e `www.integrareti.com.br` em **Settings > Domains**.
6. A Vercel mostrará os registros DNS que devem ser configurados no Registro.br.
